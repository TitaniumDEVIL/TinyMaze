# TinyMaze

A small Maze Generator and Visualizer in C++ using Raylib.

## Algorithms

| Key | Algorithm |
|-----|-----------|
| 1 | Aldous-Broder |
| 2 | Recursive Backtracker |
| 3 | Prim's |
| 4 | Hunt and Kill |
| 5 | Growing Tree |
| 6 | Binary Tree |

## Controls

| Key | Action |
|-----|--------|
| `1`-`6` | Switch algorithm |
| `R` | Regenerate |
| `Up` / `Down` | Increase / decrease FPS (animation speed) |
| `S` (hold) | Show solution path |
| `H` (hold) | Show distance heat map (new random color each press) |
| `C` (hold with `H`) | Rainbow heat map |
